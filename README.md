# ASTRA: Aether Guardians

**เกมป้องกันฐานแนวดาร์กแฟนตาซี เล่นได้บนเว็บเบราว์เซอร์**

เมื่อประตูมิติ Abyss Gate เปิดขึ้น ฝูงมอนสเตอร์เริ่มบุกโลก ASTRA คุณรับบทเป็นผู้บัญชาการที่ใช้พลังอีเธอร์เรียกเหล่าการ์เดียนมาปกป้องคริสตัลอีเธอร์จากศัตรูที่บุกเข้ามาทีละเวฟ

[**▶ เล่นเกมบน GitHub Pages**](https://wariskung.github.io/Tower-Defence/) · [ดูซอร์สโค้ด](https://github.com/WarisKung/Tower-Defence) · [รันบนเครื่อง](#run-locally)

## วิธีเล่น

1. กด **เล่นเกม** แล้วเลือกด่าน ดูรายชื่อศัตรูในแต่ละเวฟก่อนกด **เริ่มต่อสู้**
2. เลือกการ์เดียนจากแถบด้านล่าง แล้วใช้ **อีเธอร์** วางลงในจุดที่กำหนดใกล้เส้นทางศัตรู
3. กด **Start Wave** เพื่อเริ่มเวฟ จัดแนวป้องกันและใช้สกิลจากแถบซ้ายเมื่อศัตรูรวมกลุ่มหรือกำลังเข้าใกล้ฐาน
4. รับมือให้ครบทุกเวฟโดยรักษาพลังชีวิตของคริสตัลอีเธอร์ไว้

## ระบบเกม

- **การ์เดียน 6 คลาส** ได้แก่ นักธนู นักบวช อัศวิน นักเวทย์ นักฆ่า และผู้อัญเชิญ เลือกใช้ตามตำแหน่งและอีเธอร์ที่มี
- **แผนที่และเวฟเฉพาะด่าน** ศัตรูเดินตามเส้นทางบนแผนที่ แต่ละเวฟมีชุดศัตรูต่างกัน
- **สกิลสนามรบ** แถบสกิลในเวอร์ชันออนไลน์มี Meteor, Freeze, Chain และ Void
- **HUD ระหว่างเล่น** แสดงเวฟ พลังชีวิตคริสตัล และอีเธอร์ พร้อมปุ่มหยุดชั่วคราวและปรับความเร็ว

## รันบนเครื่อง

ใช้ Git, Node.js 22 และ npm คำสั่ง `cd` ด้านล่างใช้พาธสัมพัทธ์จากโฟลเดอร์ที่ Clone มาและใช้ได้บน Windows PowerShell, macOS และ Linux

```sh
git clone https://github.com/WarisKung/Tower-Defence.git
cd Tower-Defence
cd ".gemini/antigravity-ide/scratch/Tower-Defence-main"
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดงใน terminal หากต้องการสร้างและทดสอบไฟล์สำหรับเผยแพร่ ให้รันจากโฟลเดอร์เดียวกัน

```sh
npm run build
npm run preview
```
